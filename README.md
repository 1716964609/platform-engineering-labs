# Platform Engineering Labs

Hands-on research on platform standardization,
developer autonomy, and multi-tenant boundaries.

## Experiments

- Helm: templating, schema validation, library charts
- Terraform: reusable modules and configuration validation
- Kubernetes: Pods, Services, Deployments
- Gateway API: routing and multi-team ownership
- RBAC and Admission Policy: security guardrails

## Research Questions

1. How should a platform define its Golden Path?
2. How much customization should development teams have?
3. Where should Escape Hatches be introduced?
4. How can teams remain autonomous without breaking shared infrastructure?
